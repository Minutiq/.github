**Minutiq makes every meeting searchable and actionable with open-source AI.**

---

### What we're building

Build and deploy AI-powered tools that transcribe, analyze, and make meeting content instantly useful for your whole team. Connect any meeting — audio, live, or notes — and ask questions later using natural language.

---

### Key Features

- 🎤 AI transcription from audio, live meetings, or notes
- 🤖 Powered by Claude AI for deep analysis & insights
- 📝 Stores everything in ChromaDB for RAG workflows
- 🔎 Ask questions about any past meeting—instantly
- 👥 Designed for teams, privacy-friendly by default
- 🚀 100% open-source and extensible
